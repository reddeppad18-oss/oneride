# One Ride

## Overview

One Ride is a mobility platform that combines **ride sharing** and **vehicle rentals** into a single application. The platform aims to provide a convenient, affordable, and community-driven transportation solution for users across India.

Users can share rides with others traveling in the same direction, discover available rides, rent vehicles, and list their own vehicles for rental.

---

## Key Features

### Ride Sharing

* Create and publish rides
* Search available rides
* Join rides
* Manage ride bookings

### Vehicle Rentals

* List vehicles for rent
* Browse available vehicles
* Request vehicle rentals
* Approve or reject rental requests

### Authentication & Security

* Phone Number + OTP Authentication
* JWT-based Authorization
* Secure API Access

### User Management

* Unique system-generated User IDs
* User profiles
* Booking and rental history
* Notifications
